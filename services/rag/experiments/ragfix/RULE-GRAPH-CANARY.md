# Original-rule prerequisite canary

PRD-F26/F27, SDD-C21/C23 and QAD-TC44/46. This experiment cannot publish or
serve. It does not reuse coarse workflow audits to certify smaller evidence.

The graph stores every canonical original unit and identifies direct original
prerequisites and condition guards per unit. Guards are automatic prerequisite
edges. Transitive expansion includes guards and global inspection obligations.
An uncertain selected rule requires the entire source. An unrelated uncertain
rule does not expand an otherwise independently audited local rule.

Every proposed rule is independently audited against the entire original
document and its calculated closure. A failed audit, invalid address, missing
unit or stale binding prevents an artifact. Verbatim guard presence is only a
necessary mechanical check. It does not establish entailment, correct logical
qualification, absence of contradictions, or permission to release an answer.
An eventual serving design still needs independent claim verification, current
role/audience/source checks, a negotiated persistence contract and acceptance.

## Frozen offline budgets

The first 48-unit proposal exhausted 2,400 output tokens. Bounded variants at
24 and 36 units also exposed output capacity and invalid prerequisite bindings.
These failures are retained in the audit output directory. No eligible graph
was produced and chat work limits were not changed.

The next explicit, non-serving revision freezes 12 original rules per proposal
and audit batch, 70 maximum calls, 6,000,000 aggregate serialized request bytes,
80,000 aggregate reserved output tokens, 1,536 proposal output tokens, 512 audit
output tokens and a 180-second per-call timeout. Calls are serial. Full-source
input is retained for every proposal and audit. Capacity is checked before
inference and oversized documents remain ineligible. Models remain within the
existing approved set. This increases offline source-review work; it is not an
automatic paid retry or a request-time fallback.

Nested per-rule audit objects also exhausted the audit output ceiling. The
audit transport now requires one boolean for every named original rule, rather
than verbose nested missing-id lists. All rule checks and full-source input are
retained. Any false or missing key rejects the graph. This changes no budgets
or serving behavior and is not a bulk completeness verdict.

Source identity and exact original slices remain unchanged. The local ignored
cache is an experimental artifact store with no connection to serving imports,
the prepared database tables or worker deployment allowlists.
